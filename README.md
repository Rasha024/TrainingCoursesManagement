# Training Courses Management System

A static website where students can explore IT training courses, sign up, and log in.

## Pages
- **Home:** course cards, course information table, and a featured course slider
- **Login:** login form with JavaScript validation
- **Sign Up:** registration form with JavaScript validation and a password strength meter
- **About Us:** our mission, team, services, and contact details

## Technologies
HTML, CSS, JavaScript
